# 数据格式

所有文本采用 UTF-8。`data/entries.jsonl` 每行一个独立 JSON 对象，`id` 是稳定标识，重复词头保留为不同词条。

| 字段 | 内容 |
| --- | --- |
| `id`、`headword` | 词条标识、词头 |
| `categories` | 大类、子类 |
| `pronunciation.text` | 音标纯文本；无读音时为 `null` |
| `pronunciation.runs` | 保留声调位置和下划线的音标分段 |
| `pronunciation.readings` | 分别对应不同义项的读音（若有） |
| `text` | 完整释文，保留例句与原书注释 |
| `senses` | 结构化义项：编号、词性、用法标签、释义、例句 |
| `notes` | 原书以“◇”引出的释词、异写或引文 |
| `headword_runs`、`body_runs` | 词头、释文需要特殊排版时的分段 |

分段中的 `position` 为 `baseline`、`subscript` 或 `superscript`；`underline` 为 0、1、2，分别表示无、单、双下划线。`underline_style: "wavy"` 表示波浪线，`role: "inline_gloss"` 表示小字解释。音标的下划线具有语言学含义，读取时应连同分段保留。

`data/references.json` 保存出版说明、凡例和四项附录。表格的 `rows` 包含单元格；`row_span`、`column_span` 表示合并范围，单元格也可含排版分段。`text` 与 `table` 是同一内容的两种表示，无须重复展示。

```python
import json
from pathlib import Path

entries = [json.loads(line) for line in Path("data/entries.jsonl").read_text(encoding="utf-8").splitlines()]
matches = [entry for entry in entries if "𠼢" in entry["headword"]]
```
