# 助词 叹词 拟声词

## 助词

<a id="e3a0edfd65857"></a>

### 仔

tsɿ[zɿ]

❶〈助〉表示实现体，事件过去发生或已经实现：伊代我去做，我就回来～|我六岁起，连今年读～五年书|我吃～饭了。❷〈助〉表示持续体，着：坐～比立～适意。❸〈助〉在连续的行为中，表示“在……以后”：到～学堂里，伊就学好了|大家听见～，高兴得勿得了|我吃～饭再走。❹〈助〉表示伴随：我跟～两个人，一道出去了。❺〈助〉表示可能实现的假设：砚台浪个墨勿要忒浓，浓～搨勿开；也勿好淡，淡～要化|鼻头毛长～，要剪脱点。❻〈助〉表示行为的将来落定：搿点银子，换拨辣㑚～𠲎！|侬今朝就住～一夜好了。❼〈助〉表示行为所至：做生意个人，坐～里向去哉。❽〈助〉表示催促、命令的语气：坐好～！|痰盂倒脱～！❾〈助〉表示提醒、警告的语气：侬当心勿要拿伊冻杀～|门应该锁好～。❿〈助〉表示现状的语气：看见伊，满头个火，眼睛弹出～。⓫〔旧〕语缀，地：轻轻～一揩就揩脱。◇字源是“着(著)”，虚化失去韵母读声母延长音。俗又写作“之”。

<a id="e57d7dab646f6"></a>

### 好仔

hɔtsɿ

完以后：饭吃～再做|看～睏。

<a id="ef98527a8503f"></a>

### 了

ləʔ

❶〈助〉表示实现体，相当于普通话的“了”：我上了两节课|侬吃了饭再做|小王做了售票员。◇老上海话用“仔[tsɿ/zɿ]”。“仔”词条下第❶、❸、❹、❺义项都可改用“了”。❷〈助〉在动词后带结果补语：篮头吊～高一点。◇老上海话用“来[lᴇ]”，现今也能改用“得”或“得来”。❸〈助〉作过去叙事的语气词：讨论得呒没结果，大家就回去～。❹〈助〉表示事件的现在状态：落雨～|苹果熟～|想起来～。❺〈助〉与进行体助词“辣辣/辣海”一起，表示现在进行时态：侬看，客人辣辣来～。|大楼辣辣造～。❻与存续体助词“辣海/辣辣”一起，表示现在完成时态：物事我买辣海～|四只冷盆摆辣海～。❼与表示即行的“快”一起用，表示现在即行时态：火车开快～。❽与句中表示时间的词语一起用，表示当时状态：伊昨日夜里回来～|伊明朝勿来～。❾〈助〉表示申明、表白的语气：搿个办法我觉着最好～|侬双鞋子忒小～|有三十万～|我写勿来～。❿〈助〉表示劝听、商量的语气：好唱歌～|㑚勿要去～|好～，好～，大家勿要吵～。⓫〈助〉表示现状的语气：闷煞～|葛倒希奇极～|非但搿趟事体，还有一桩勿开心事体～。◇这里的“了”都能用“辣海”替换。⓬〈助〉用于假设、条件、直推、转折的复句的正句最后结尾：风一吹末地板就干～|只要用功末，功课就好起来～|既然伊勿欢迎，阿拉勿去～|虽然伊已经老用功，但是到底还赶勿上～。◇除了义项⓫和⓬里的“虽然……但是……”一句，老上海话都用“拉”说外，从❸到⓬的各句老上海话都用“哉(tsᴇ/zəʔ)”说。“了”又写作“勒”。

<a id="e19249a75f620"></a>

### 过

ku

❶〈助〉表示经历体：我看～搿部电影|衣裳我汏～了。◇上海话常用经历体助词“过”表示完成，如“我饭吃过了”。❷〈助〉在将来发生状态的句子中，表示重行体，即再来一次：侬觉着菜忒生了𠲎？再烧～！◇老上海话中“再烧过”中的“再”可以不说，今这个体形式已经退化，故要用个“再”或“重”重复表示。

<a id="e4b8a345b4682"></a>

### 过歇

kuɕiɪʔ

〈助〉表示经历体，常用于表示曾经有过此种经验：搿块地方我来～|侬蛇吃～𠲎？

<a id="eaac095c12630"></a>

### 歇

ɕiɪʔ

〈助〉表示经历体，常用于曾经有过的经验：侬看见～鬼𠲎？

<a id="ec3dc042fe25f"></a>

### 歇过

ɕiɪʔku

〈助〉表示经历体，是“过”和“歇”综合，多用于曾经有过的经验：我做～搿种生活。

### 正辣(辣)

tsən lᴀʔlᴀʔ/tsən lᴀʔ

〈副〉正在：我去叫伊个辰光，伊～换衣裳。

<a id="ecc4bf6f4fa44"></a>

### 来

lᴇ

❶正在(表示进行体)：侬勿要叫伊，伊～做功课。❷〈副〉很；非常；多么：鱼汤鲜～！❸〈助〉〔旧〕得：做～人坍垮脱|吃力～勿得了！❹〈连〉连接连动结构，常表示前一动作是后一动作的方式：我拿笔～写字|让我自己烧～吃|阿有酒～拨我吃？

<a id="e8bdcfb26098c"></a>

### 看

k‘ø

表示动作的尝试态：试试～|吃吃～|买买～|生生～|试验试验～。

<a id="ed2afa5ccc90e"></a>

### 辣海仔

lᴀʔhᴇtsɿ[zɿ]

〈助〉“辣海”表示“在里面”、“在那儿”，加上强调将来实现的祈使语气的“仔”，表示命令保持的语气：衣裳囥～！|侬脱我先坐～！|搿点小菜留～，爸爸回来吃。

<a id="e4761890d73de"></a>

### 辣海了

lᴀʔhᴇləʔ

❶“辣海”在此表示延续，“了”表示当下现状，合起来表示现在完成时态：簿子摆～|钟点工请好～|台子浪四只冷盆端正～。◇旧上海话用“拉哉”。❷还……着呢：辰光早～|伊小～，勿要要求忒高。◇“了”又写作“勒”。

<a id="eeee79fb655d7"></a>

### 辣里

lᴀʔli

〔旧〕同“辣(辣)”。◇老上海话“垃里”指近，在这儿，“垃垃”指远，在那儿。“垃”同“辣”。

<a id="e9e2b1e6acb77"></a>

### 辣了

lᴀʔləʔ

〈助〉表示动作完成后其状态延续的“辣”加上表示现在状态的“了”，合起来表示现在完成：我个衣裳完全出出汗湿～|伊死～|被头盖～。◇“了”又写作“勒”，旧上海话用“拉哉”，今新派极少用，一般场合只用“了”，“辣”已省却。如：“被头盖了”、“伊死了”。

<a id="ea645b647a116"></a>

### 辣哉

lᴀʔzᴇ

〔旧〕同“辣了”。

<a id="e38600de2fad6"></a>

### 好辣

hɔlᴀʔ

〈助〉表示动作达到完善。也表示动作完成后其状态的延续。用法相当于“好辣海”：我坐～旁边|衣裳摆～抽屉里。

<a id="e209299a18bc0"></a>

### 要……了

iɔ……ləʔ

表示现在将要进行：我要去打电话了|许老师要骂我了。

<a id="e904f0b165e21"></a>

### 辣海个

lᴀʔhᴇɡəʔ

用在动词后面表示过去完成时态：条子我写～，侬寻出看看好了。

<a id="e9bcd5d5de059"></a>

### 脱

t‘əʔ

❶〈助〉掉，表示结果的补语：菜已经卖～|衣裳退勿～，只好认下来|垃圾脱我扫一扫～|飞机飞～。❷〈助〉了，表示结果的助词，表示动作性质变化的实现：我看～一歇再去上课|伊踢～我三脚|衣裳小～一眼。❸〈助〉结构助词，起强调作用：侬话～伊两声勿要紧个。❹〈动〉滑而不着实：链条～出来了|螺丝捻勿牢，～进～出。❺〈动〉取下，去掉：～皮|～帽。

<a id="e23efbe6a7872"></a>

### 脱仔

t‘əʔtsɿ[zɿ]

❶〈助〉表示动词补语的“脱”加表示完成态的“仔”：一本书拿去还～算数。❷〈助〉表示动作结果的助词的“脱”加表示完成态的“仔”：当心做坏～！❸〈助〉起强调作用的“脱”加表示完成态的“仔”：我等～侬两个钟头。

<a id="e4121038bd0f5"></a>

### 脱了

t‘əʔləʔ

同“脱仔”。

<a id="e1eb68aa1e0c1"></a>

### 得

təʔ

❶〈助〉带补语：侬跑～快跑勿快？|篮头吊～旁边一眼<small>一点</small>。❷〈助〉能，带表示可能的补语：搿只凳子我拿～动|搿眼缺点我改～好。❸〈助〉词缀：搿眼苦我吃～消，受～住|侬魂灵头拨伊勾～去了？

<a id="e7ab0de33bcc4"></a>

### 末

məʔ

❶〈助〉提顿话题：新衣裳～，我已经买了两件|孙～，就是孙中山个孙。❷〈助〉提顿拷贝式句：做～做勿动，吃饭～吃得落来死。❸〈助〉提顿假设分句，相当于“如果”或“即使”：侬勿去苏州～，要告诉我一声|呒没汽车～，阿拉也要赶得去个。❹〈助〉提顿条件分句，相当于“只要”：侬用功～，功课再会好。❺〈助〉表示当然语气，本应如此，显而易见：干部～，应该带头～！|搿个人本来勿来事～。❻〈助〉表示劝听、商量语气：阿拉就等伊一歇～！|侬就快点去～！❼〈助〉〔旧〕表示完成体的疑问式语气：主意定当拉～？|侬已经攀亲～？

<a id="e86dcd9dcb7e4"></a>

### 唻

lᴇ

❶〈助〉表示申明、表白的语气：我里向还好个产品～|有三十万～。❷〈助〉表示劝听、商量的语气：算～，勿要脱伊去争～|吃力煞了，让我坐脱一歇～！❸〈助〉表示提出、指明的语气：侬让我走一走～|拨我戳戳看～|白送拨我我还勿要～。❹〈助〉表示延续的语气：事体还呒没完～|现在辰光呒没到～。❺〈助〉表示反对、轻蔑的语气：讲伊老实，还老实～！|真也勿清白～！|啥人要脱侬好～！❻〈助〉表示提醒、警告的语气：侬可以回去～！|我明明看见个，还要赖～！|侬明朝好勿要来～！❼〈助〉表示羡慕、称赞的语气：侬屋里三房两厅～！|搿只电视机最好～！❽〈助〉表示责怪、气愤的语气。❾〈助〉表示现状语气：做煞～|还有一桩猜勿出个事体～。❿表示程度高：五斤肉十块洋钿～！◇部分语义相当于旧时的“哉”。

<a id="ee03dd8e8c2ef"></a>

### 哉

tsᴇ[zəʔ]

❶〈助〉〔旧〕表示过去叙事情况下的语气：过一歇，伊又出去～|后来我去睏～。❷〈助〉〔旧〕表示事件的现在状态：生病～|钟停～|苹果熟～|三点钟～|天晴～。❸〈助〉与进行体助词“辣辣/辣海”一起，表示现在进行时态：伊辣辣读书～|大楼辣海造～|伊辣来～。❹与存续体助词“辣海/辣辣”一起表示现在完成时态：奶妈请辣海～|我家生买辣辣～。❺与表示即行的“快”一起用时，表示现在即行时态：水开快～|苹果熟快～。◇以上是“哉”的主要用法，“哉”在上海话中后被“了(勒)”取代，故作为语气助词“了”的第❾至⓬项义项，都与“哉”通。

<a id="e59d70019fcf2"></a>

### 𠲎

vᴀ

❶〈助〉表示是非问，吗：侬到松江去～？❷〈助〉表示推测、料想语气，吧：车子还呒没来～？|勿会是伊～？|我看未必～。❸〈助〉表示商量、劝听的语气：侬就唱一只～|下个月个工钿一道拨我仔～。❹用于假设句的结尾：假使伊答应个闲话，侬就去～|只要大家开心，侬就放心～。

<a id="e3a3c52ba8cdb"></a>

### 呢

ni/nəʔ

❶〈助〉表示特指问、选择问：要等到啥辰光～？|伊来～勿来？❷〈助〉表示省略的特指问：我个书包～？|万一伊一定勿肯来～？❸〈助〉表示责备怨憎的语气：早点介讲～！到现在再讲|侬做得快点～！

<a id="e1569c9790a84"></a>

### 啊

㊀ᴀ<br>㊁ɦᴀ<sub>23</sub>

㊀❶〈助〉表示呼语：老王～！侬快点来。❷〈助〉表示感叹语气：真气煞人～！❸〈助〉表示催促、命令语气：走～，走～！勿要等辣此地|快点讲～！❹〈助〉表示叮嘱语气：侬当心点～！|书包带好，～！❺〈助〉表示劝听、商量语气：侬就唱一只～！|侬也要脱伊讲一声～！❻〈助〉表示敷衍、答应语气：好～，葛末大家走～！|可以～，侬做好唻！❼〈助〉表示怀疑语气：勿要是骗骗我～！❽〈助〉表示称赞语气：侬真贴心～！|造得介快～！❾〈助〉表示特指问、选择问、是非问语气：侬要哪能～？|侬是苏州人还是温州人～？|搿种地方侬想去～？❿〈助〉表示反问、诘问语气：难道侬真个勿相信～？⓫〈助〉表示催问、责问、追问语气：侬讲勿啦，～？|侬啥个意思，～？|真个～？|啥个～？～？⓬〈助〉表示确认问语气：哪能，还呒没做～？⓭〈助〉表示过程长语气：写～写～，到现在还辣写～。⓮〈叹〉表示感动或激动：～！我儿化同情侬～！|～！真适意！㊁❶〈助〉表示叮嘱的语气：侬要当心点～！|对付伊，侬要下决心，～！|书勿要忘记带，～！❷〈助〉表示确认问的语气：要通知伊𠲎，～？|勿妨试伊一试，～？❸〈叹〉因未听清表示询问：～？侬再讲一遍！|～？讲响一点好𠲎？❹〈叹〉表示惊讶，出人意外，什么：～，伊死脱了？|～，伊会得从楼梯浪摜下来？❺〈叹〉表示疑问、诘问：～？伊真个是警官～？|～？会个顺利个𠲎？

<a id="e90fe15069c04"></a>

### 呀

iᴀ

❶〈助〉表示催促、命令的语气：冲上去～！|走～！走～！勿要挡牢人家！❷〈助〉表示警告、提醒的语气：侬去告诉伊拉娘～！❸〈助〉表示劝听、商量的语气：侬去买副眼镜戴戴～！❹〈助〉表示限制的语气：无非吃吃香烟～，有啥关系！❺〈助〉表示重申的语气：我勿会答应个～！❻〈助〉表示感叹的语气：真是勿懂事体～！❼〈助〉表示反驳的语气：我并呒没答应～！❽〈叹〉惊叹、赞叹：～，落雪啦！|～，真好看！

<a id="eb9a585ad8253"></a>

### 啦

lᴀ

❶〈助〉表示是非问、选择问、特指问：功课做好～？|侬自己来勿来～|付也付脱了，有啥舍勿得～？❷〈助〉表示追问的语气：哪能办～？❸〈助〉表示催问、责问语气：侬啥辰光跟我一道走～？|我拨侬个好处忘记脱～？❹〈助〉表示埋怨、责备语气：侬哪能介糊涂～！❺〈助〉表示讨厌、责备语气：侬做啥～！碰着我。◇义项❶的“啦”是“了”和“啊”的合音。

<a id="e6ef44a407599"></a>

### 噢

ɔ

❶〈助〉表示提醒、警告语气：勿好出去～！|当心点～！❷〈助〉表示告知语气：马上就好～！|等一歇～！❸〈助〉表示叮嘱语气：勿要忘记借书～！|书带好，～！❹〈助〉表示劝听、商量语气：马上就走～！|帮帮我忙～！

<a id="e745d72a2476f"></a>

### 嚎

ɦɔ

❶〈助〉表示反驳语气：我呒没做错～|侬昨日出去了？——呒没～，一直辣屋里。❷〈助〉表示确认问语气：伊老来三个～？|侬想吓吓我～？❸〈叹〉表示惊讶，出人意外：～，伊倒有汉朝个铜壶个？|～，伊买得起别墅个啊！❹〈叹〉表示疑问、诘问：～，伊还呒没结婚啊？|～？我倒勿晓得嗒。❺〈叹〉表示醒悟、领会：～，原来伊介坏啊！

<a id="eb1841bfafbe3"></a>
