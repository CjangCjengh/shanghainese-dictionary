# 附录（二）上海话连读变调

## （二）上海话连读变调

## 1. 第一式：一个语音词内的连读变调

<table>
<tr><td>代码调式</td><td>单字调</td><td>二字调</td><td>三字调</td><td>四字调</td><td>五字调</td></tr>
<tr><td>1. 阴平式</td><td>53</td><td>55＋21</td><td>55＋33＋21</td><td>55＋33＋33＋21</td><td>55＋33＋33＋33＋21</td></tr>
<tr><td>5. 阴去式</td><td>34</td><td>33＋44</td><td>33＋55＋21</td><td>33＋55＋33＋21</td><td>33＋55＋33＋33＋21</td></tr>
<tr><td>6. 阳去式</td><td>23</td><td>22＋44</td><td>22＋55＋21</td><td>22＋55＋33＋21</td><td>22＋55＋33＋33＋21</td></tr>
<tr><td>7. 阴入式</td><td><u>55</u></td><td><u>33</u>＋44</td><td><u>33</u>＋55＋21</td><td><u>33</u>＋55＋33＋21</td><td><u>33</u>＋55＋33＋33＋21</td></tr>

说明：两字以上的连读变调调型大致是单字调调型的延伸模式。

## 2. 第二式：两个、多个语音词之间的连读变调

<table>
<tr><td>发生变调的位置</td><td>1. 阴平调</td><td>5. 阴去调</td><td>6. 阳去调</td><td>7. 阴入调</td><td>8. 阳入调</td></tr>
<tr><td>只有一个字时</td><td rowspan="2" colspan="2">44</td><td rowspan="2">33</td><td rowspan="2"><u>44</u></td><td rowspan="2"><u>22</u></td></tr>
<tr><td>上个单字后的单字</td></tr>
<tr><td>二字、多字组的末字</td><td rowspan="2" colspan="3">33</td><td rowspan="2" colspan="2"><u>33</u></td></tr>
<tr><td>上个二字、多字组后面较紧密的单字</td></tr>
</table>

说明：如果一个词语是用两个或几个语音词连续而成，即该词语内部有语音上的小停顿一处或多处，在两个语音词相接的时候，在通常的语流中，前个语音词的末尾音节的声调会发生中性化的现象，读成一个简化的平调，上表列出的变调调值就是发生变读的那个音节上的读法。该词语的其他音节都按第一式连读变调读。第二式的变调是非音位式的，如果用慢速读，两个语音词之间相接也可以都分别读第一式变调，而不用第二式连读。
